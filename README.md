# GAS開発テンプレート（非エンジニア向け）

プログラミングの知識は不要です。やりたいことを日本語でClaude Codeに伝えるだけで、Google Apps Script（GAS）の開発ができます。

---

## セットアップ手順（最初の1回だけ）

### ステップ1：Node.js をインストールする

clasp（GASをローカルから操作するツール）を動かすために必要です。

1. ブラウザで https://nodejs.org を開く
2. 「LTS」と書かれた緑のボタンをクリックしてダウンロード
3. ダウンロードしたファイルをダブルクリックして開く
4. 「Next」を押し続けて最後に「Install」→「Finish」
5. すべてデフォルト（初期設定）のままでOK

### ステップ2：Git をインストールする

コードの変更履歴を記録するツールです。「昨日の状態に戻したい」ができるようになります。

1. ブラウザで https://git-scm.com を開く
2. 「Download for Windows」をクリックしてダウンロード
3. ダウンロードしたファイルをダブルクリックして開く
4. 「Next」を押し続けて最後に「Install」→「Finish」
5. すべてデフォルト（初期設定）のままでOK

### ステップ3：Apps Script API を有効にする

この設定をしないと、Claude CodeがGoogleにアクセスできません。

1. ブラウザで https://script.google.com を開く（Googleアカウントでログイン）
2. 左側メニューの「設定」（歯車アイコン）をクリック
3. 「Google Apps Script API」を「オン」に切り替える

### ステップ4：Claude Codeに残りをお願いする

Claudeデスクトップアプリの「コード」タブを開き、こう伝えてください：

> 「GASの開発環境をセットアップして」

ブラウザが開いたら、Googleアカウントでログインして「許可」を押してください。
それ以外はすべてClaude Codeが自動で行います。

### セットアップできたか確認する

> 「セットアップできてるか確認して」

と聞けばClaude Codeが確認してくれます。

---

## 日常の使い方

### あなたがやること

1. Claudeデスクトップアプリの「コード」タブを開く
2. やりたいことを日本語で伝える
3. スプレッドシートを開いて動作確認する
4. 問題があればClaude Codeに伝える

### 伝え方の例

- 「シートAのA列〜C列のデータを集計して、シートBに書き出す機能を作って」
- 「毎朝9時に自動でメールを送る機能を追加して」
- 「エラーが出たので直して」（エラーメッセージを貼り付ける）
- 「昨日の状態に戻して」

コードを書くこと、Googleに反映すること、デプロイすることはすべてClaude Codeが行います。

## GASの制限（知っておくと便利）

| 制限 | 内容 |
|------|------|
| 実行時間 | 1回の実行は最大6分 |
| メール送信 | 1日100通まで |
| トリガー | 時間指定の自動実行は最小1時間間隔 |
