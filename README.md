# GAS開発テンプレート（非エンジニア向け）

プログラミングの知識は不要です。
やりたいことを日本語で伝えるだけで、AIがGoogle Apps Script（GAS）を開発してくれます。

**GASとは？**
Googleスプレッドシートやフォームを自動化できるしくみです。
例えば「毎朝データを集計してメールで送る」といったことができます。

## セットアップ手順

全部で5ステップあります。すべてクリック操作で完了します。

### ステップ1：Claude Desktop をインストールする

AIと会話しながら開発するためのアプリです。

1. ブラウザで https://claude.ai/download を開く
2. お使いのOS（Windows / Mac）に合ったものをダウンロード
3. ダウンロードしたファイルをダブルクリックしてインストール
4. インストール後、アプリを起動してAnthropicアカウントでログイン

**注意：** Proプラン以上（有料）への加入が必要です。
無料プランではコード機能（Code タブ）は使えません。

### ステップ2：Git をインストールする

Claude Codeを動かすために必要なツールです（自分で操作する必要はありません）。

1. ブラウザで https://git-scm.com を開く
2. 「Download for Windows」（Macの場合は「Download for Mac」）をクリック
3. ダウンロードしたファイルをダブルクリック
4. 「Next」を押し続けて最後に「Install」→「Finish」
5. すべてデフォルト（初期設定）のままでOK
6. **インストール後、Claude Desktop アプリを再起動してください**

### ステップ3：Node.js をインストールする

GASのコードをGoogleに送るツール（clasp）と、ローカルでの動作検証に必要です。

1. ブラウザで https://nodejs.org を開く
2. 「LTS」と書かれた緑のボタンをクリックしてダウンロード
3. ダウンロードしたファイルをダブルクリック
4. 「Next」を押し続けて最後に「Install」→「Finish」
5. すべてデフォルト（初期設定）のままでOK
6. **インストール後、Claude Desktop アプリを再起動してください**

### ステップ4：Apps Script API を有効にする

この設定をしないと、AIがGoogleにアクセスできません。

1. ブラウザで https://script.google.com を開く（Googleアカウントでログイン）
2. 左側メニューの「設定」（歯車のアイコン）をクリック
3. 「Google Apps Script API」を「オン」に切り替える

### ステップ5：このテンプレートをダウンロードして開く

1. このページ上部にある緑色の「Code」ボタンをクリック
2. 「Download ZIP」をクリック
3. ダウンロードしたZIPファイルを右クリック →「すべて展開」
4. 展開先はどこでもOKです（デスクトップやドキュメントなど）
5. Claude Desktop アプリを開く
6. 画面上部の「コード」タブをクリック
7. 「Local」を選択
8. 「Select folder」をクリックして、展開したフォルダを選ぶ

## 使い始める

フォルダを開いたら、以下のメッセージを送ってください：

> 「GASの開発環境をセットアップして」

AIが自動で残りのセットアップを行います。
途中でブラウザが開いたら、Googleアカウントでログインして「許可」を押してください。

セットアップが完了したら、やりたいことを日本語で伝えるだけです。

---

## 使い方の例

こんなふうに話しかけてください：

- 「スプレッドシートのA列とC列のデータを集計して、別のシートに書き出して」
- 「毎朝9時に自動でメールを送る機能を作って」
- 「フォームの回答をスプレッドシートに自動で整理して」
- 「エラーが出たので直して」（エラーメッセージをコピーして貼り付ける）

コードを書くこと、Googleに反映すること、デプロイすることはすべてAIが行います。

---

## AIの開発の流れ（参考）

AIは以下の流れで開発を行います。あなたが意識する必要はありませんが、参考までに記載します。

1. **コードを書く** — あなたの指示にもとづいてGASのコードを作成
2. **ローカルで動作検証** — Googleに送る前に、PC上で動作確認して不具合を修正
3. **確認** — 問題なければ「Googleに反映していいですか？」とあなたに確認
4. **Googleに反映** — あなたがOKしたらGoogleに送信
5. **ブラウザで最終確認** — 必要に応じてスプレッドシート上での確認をお願いすることがあります

| 制限 | 内容 |
|------|------|
| 実行時間 | 1回の実行は最大6分 |
| メール送信 | 1日100通まで |
